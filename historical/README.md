# Historical helper sources

These files were copied verbatim from retained Issue 379 working directories
on `wspr5.local` on 2026-08-11. They are preserved to avoid losing the tested
algorithms and capture behavior.

They are not a supported API and must not be executed as a live harness without
review. They contain Unix paths, shell assumptions, fixed parameters, and
issue-specific behavior. The future implementation should port the applicable
logic into tested cross-platform components rather than modify these files in
place.

See `../provenance/README.md` and `../provenance/SHA256SUMS`.
