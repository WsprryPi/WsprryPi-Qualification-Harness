## Safety boundary

Do not invoke the live-tone command, stop services, open the SDR, touch GPIO,
start the dedicated transmitter, enter an RF confirmation, or transmit. This
slice prepares a candidate; it does not authorize one.

Keep all local profiles, plans, helper configurations, credentials, backups,
and run evidence outside Git. Commit and push only this durable prompt or a
separately justified source/test correction. Require green macOS, Ubuntu, and
native Windows CI at the resulting tracked revision.

## Exit criteria

Exit when the fresh candidate is internally coherent, staged byte-for-byte,
read-only preflight is clean, the old evidence remains immutable, services and
hardware are undisturbed, repository CI is green, and the new canonical digest
is ready for separate one-run authorization.
